# 救救小編（山頂國小）

山頂國小同人小遊戲，玩法照「蜜蜂叮狗狗（Save the Doge）」：玩家是**兔兔老師**，用手指畫一條粉筆線護住**小編**，撐過倒數、不被蜂窩飛出來的蜜蜂叮到就下課。粉筆用得越少，老師蓋的「優」越多（最多三個）。上學期 15 關＋下學期「大力蜂來了」10 關，免費、不用登入，沒有儲值、等待或廣告。

**線上玩：** https://pokemonida99.github.io/shanding-save/

- 開啟：`python3 -m http.server 4500 --bind 0.0.0.0 --directory shanding-save`（上層 `.claude/launch.json` 的 `shanding-save`），手機連同一個 Wi‑Fi 開 `http://<電腦IP>:4500/`
- 手機直式為主，畫面一律填滿：長螢幕往上加長、比較矮的螢幕（Safari 有網址列、16:9 手機、電腦橫螢幕）往兩邊加寬，貼邊的地板、池子會往外延伸接上（物理不變，關卡永遠在正中間 720 寬）。
- 全螢幕：Android／電腦按「開始上課」或「選關」會自動進全螢幕；iPhone Safari 不支援，封面提示「分享 → 加入主畫面」。

## 程式

- `js/sim.js` 物理（Matter.js 2D，瀏覽器與 node 共用）：從黃泉燒肉店版「紅線護軍師」移植，鼠軍師→小編、蝙蝠→蜜蜂、燈籠→蜂窩，數值與 AI 完全沒動
- `js/levels.js` 關卡：上學期 15 關（佈局照紅線護軍師，換成教室／操場／傍晚走廊三個場景，`bg` 欄位指定）；下學期 10 關（`term: 2`、`strong`＝大力蜂幾隻），兩個學期各自從第一關解鎖

## 大力蜂（下學期）

- 大力到不像蜜蜂：半徑 40（一般 15，快三倍大）、密度 0.05（一般 0.0005）、飛得比一般快；3D 是橘色、粗手臂＋二頭肌＋大拳頭、生氣眉毛、紅色運動頭帶，推的時候前傾、雙拳往前頂
- 撞到粉筆線那一下會**把線撞飛**（直接改線的速度＋轉動，線越重飛越近；碰撞事件後 Matter 會清掉 force，所以不能用 applyForce），接著橫著往小編那邊推、往上抬，退一下再衝；畫面震動＋粉筆灰＋「碰！／轟！」＋重低音
- 調參踩過的坑（`STRONG` 在 `js/sim.js` 開頭）：
  - 往下壓推不倒線，要橫推＋往上抬
  - 只推的話，線會連小編一起被推著走（像推土機），小編一直被罩著 → 要「撞飛」
  - 撞飛一次給太快（一格 27 px）線會穿隧跳過小蜜蜂，小蜜蜂跑進線裡 → 每次最多加 `maxV` 9 px／格、`maxW` 0.06 弧度／格
  - 大力蜂會把小蜜蜂硬擠穿線 → 大力蜂跟小蜜蜂用 collisionFilter 互相穿過
- 結果：空曠地上的拱、靠柱子、卡坑、勾台子都擋不住（上學期解答換成有大力蜂，12 次幾乎全輸），**只有把線繞台子一圈扣住**撞不走。下學期 10 關都是小編站在台子上，解答是 `levels.js` 的 `wrap()`（繞台子＋小編一圈的圓角框，底部留 14 px 縫），40 種子全勝
- 下學期：大力蜂來了、繞一圈、下面也來、圖釘海、窄窄板凳、高高在上、小板凳、生態池、蜂擁而至、蜂王的保鑣（5 隻大力蜂、12 秒）

## 角色

- 模型沿用《下班先鬥牛》的山頂國小隊：`models/bian_walk.glb`＝小編、`models/tu_walk.glb`＝兔兔老師；招牌動作 `models/sig/`、共用動作 `models/moves/`（踉蹌、抄截前撲、防守張手、舉手、歡呼）
- 小編：平常站著呼吸；蜜蜂靠近發抖、蹲低張手、頭上「!!」；被叮踉蹌＋「好痛」；過關播勝利歡呼＋「耶～」
- 兔兔老師站在關卡下面的走道（`BAND` 170 px）：畫線時走到筆尖底下、雙手舉高施法，手上飄粉筆灰到筆尖；放開手指往前一揮；過關跳舞、失敗踉蹌
- 3D 不拉近特寫（模型近看會露破綻）

## 改關卡

改完一定要跑：

```
node tools/verify.js
```

每關用 `sol` 解答實跑多個亂數種子（必須全勝），並確認不畫線會輸；`SEEDS=40 node tools/verify.js` 加測、`node tools/verify.js 12` 只測第 12 關。第 12 關原本的解答 40 次會輸 2 次，已換成更穩的弧線（40/40）。

## 物理注意（沿用紅線護軍師修好的坑）

- Matter 組合物體的轉動慣量沒算平行軸，粉筆線會轉得像紙片 → `commit()` 裡自己補慣量
- 一大群蜜蜂一直壓會把線擠走 → 蜜蜂撞到東西會彈開一下（`back`），`slop: 1`
- 蜜蜂 AI：格子尋路找縫鑽（`buildFlow`）、封死時六成去撞線頭撬線、蓄力猛撲
- 畫線：碰到東西貼邊停住、按在東西上也能開始（手指移到空地才落筆）、加點放在 rAF 裡

## 美術方向

「山頂國小教室」：黑板綠、粉筆白、課桌木頭、作業簿紙、老師的紅色「優」印章。字型霞鶩文楷 TC（手寫感）。不用粉彩漸層、大圓角、emoji 圖示。

- 小黑板按鈕、標題牌：GPT 畫的木框黑板 `art/ui-board.webp` 切九宮格
- 提示、選關卡片、結算「聯絡簿」：GPT 畫的作業簿紙 `art/ui-paper.webp`
- 粉筆條：木頭粉筆槽上一根粉筆，畫越多越短；倒數是教室時鐘
- 標題字 `art/logo.webp`：GPT 粉筆字（黑底轉透明），剛好寫在背景的黑板上
- 生圖：`zsh tools/prompts.sh [名稱]`（用 `tools/gen.sh` 呼叫 ChatGPT.app 的 codex，原圖在 `work/gen/`，不進 git）
- 主畫面圖示 `icon-*.png`：小編原本的三視圖正面（籃球遊戲 `work/3d/bian_front.png`）Vision 去背，貼在 GPT 黑板上
